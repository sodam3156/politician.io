# politician.io · 이거 누가 발의했어?

정치인의 말과 행동을 공식 근거로 잇는 오픈소스 프로토타입입니다.
관심 정책 → 생활에 어떤 변화를 제안하는지 → 기존 내용과 제출안 비교 → 발의자와 공식 근거 순서로 읽습니다.
인기 순위, 정치 성향 설문, 진정성 점수는 제공하지 않습니다.

홈은 중앙 명조 제호, 정책 선택, 제목·사진·핵심 정보의 신문형 지면입니다.
법률명 대신 원문의 변경 내용을 쉽게 풀어 쓴 제목을 먼저 표시합니다. 법률명과 의안번호는 보조 식별자로 남깁니다.
설명은 `src/policy-briefs.ts`에서 제출안의 제안이유·주요내용을 수동 검토한 편집 콘텐츠입니다. 자동 요약이나 전체 의안 서비스가 아닙니다.
의안 ID·번호·제목·제안일이 모두 일치할 때만 표시하며, 새 의안에는 추정 설명 대신 확인 중 상태를 표시합니다.
기존 내용 / 제출된 안 / 생활에서의 의미 / 확대해석하면 안 되는 점 / 공식 출처를 구분합니다.
제출안 설명을 최종 의결 조문이나 시행 중인 혜택으로 취급하지 않습니다. 원문·절차 갱신 시 설명도 다시 검토해야 합니다.
검색은 법률명뿐 아니라 검증된 설명의 ‘간병비’, ‘기본공제’ 같은 일상어도 찾습니다.
법안 상세와 정치인 맥락 화면에서 YouTube·NAVER 원문 검색을 직접 실행할 수 있습니다.
발급·연결 설정은 별도 `#/data` 화면입니다. 일반 사용자 진입 주소는 `#/`입니다.
포함된 정책 사진 6개는 이 프로토타입을 위해 AI로 생성한 주제 이미지이며 실제 사건의 증거가 아닙니다.

`politician.io`는 저장소 이름입니다. 도메인 소유나 운영 중인 공개 서비스를 의미하지 않습니다.

## 실행

Node.js 24와 npm이 필요합니다.

```sh
npm ci
npm run dev
```

[로컬 프로토타입](http://127.0.0.1:8770/)을 엽니다.
배포 파일 확인은 `npm run build` 후 `npm run preview`로 합니다.
개발 서버와 미리보기는 같은 포트를 사용하므로 동시에 실행하지 않습니다.

소스만 복제하면 **API 미수집 상태**에서 시작합니다. 실제 원문을 수동 검토한 국정원법 사례만 표시됩니다.
사용자의 키, 대량 수집 스냅샷, 개인 기획 자료는 저장소에 포함하지 않습니다.

## 국회 실제 자료 연결

1. [열린국회정보](https://open.assembly.go.kr/)에서 본인의 이용 조건과 인증키를 확인합니다.
2. Windows PowerShell에서는 다음 보안 입력 창에 키를 입력합니다. 입력은 숨겨지고 파일에 저장되지 않습니다.

```powershell
./scripts/sync-secure.ps1 -Full
```

다른 환경에서는 비밀 관리 도구로 `ASSEMBLY_API_KEY`를 **프로세스 환경변수**에 주입한 후 실행합니다.

```sh
npm run sync:assembly -- --full
npm run build
```

키를 명령 인수·브라우저·소스·이슈에 붙여넣거나 `VITE_` 변수로 설정하지 마세요.
`.env`를 자동으로 읽는 수집기가 아닙니다. 키 없는 공개 샘플 수집은 `npm run sync:assembly`입니다.
키가 있어도 `--full`이 없으면 샘플 모드입니다.

## YouTube·NAVER·이미지의 데이터 출처 연결

[API 발급·등록 안내](API_SETUP.md)에 여섯 출처의 공식 링크와 필요한 키를 정리했습니다.
Windows 보안 도우미 `./scripts/connect-data.ps1`에서 키를 등록하고 `npm start`를 실행하면,
[로컬 연결 화면](http://127.0.0.1:8771/#/data)에서 국회 갱신 및 정치인별 뉴스·영상 원문 검색을 사용할 수 있습니다.
키는 Windows 계정 전용 암호화 보관함에 두고, 브라우저·Git·검색 로그에 노출하지 않습니다.
NAVER 검색결과는 독립 표시만 하며 기존 제목 분석·내보내기에 자동 연결하지 않습니다.
새 키의 실제 인증 성공은 실제 요청 후 확인합니다. 외부 제공처 계정·승인 없이 작동한다고 보장하지 않습니다.

선택 의안은 2221107, 2220987, 2221061, 2221082, 2221086, 2217540입니다.
이것은 **선택한 여섯 의안의 기록**이며 전체 국회의원 경력·전체 법안의 전수 분석이 아닙니다.
전체 수집 성공 여부와 인원·행 수는 각 실행 결과로 확인하세요.

수집 상한은 64요청·180초·서비스당 50페이지·개별 요청 15초, 자동 재시도는 0회입니다.
실패하면 기존 스냅샷을 보존합니다. 성공 직전 버전은 `.local/assembly.previous.json`으로 보관합니다.
복원하려면 그 파일을 `public/data/assembly.json`에 복사한 뒤 다시 빌드합니다.
호출 출처·시각·행 수를 기록하지만 인증키나 원본 오류 응답은 저장하지 않습니다.
현재 정기 수집이나 서버 알림은 없습니다. 화면의 ‘자료 재읽기’는 API 수집 실행이 아닙니다.

## 제공 범위와 한계

- 실제 기능: 정책·인물·법안 탐색, 대표/공동발의와 표결 구분, 원문 근거 확인, 두 인물의 한 안건 해석, 조건부 시나리오, 로컬 추적·변경 확인·내보내기.
- 수동 검토: `src/politics-reviewed.ts`의 의안 2217540 발언·해석. 임시회의록은 정정될 수 있으며 후속 검토가 필요합니다. 새 API 사실이 우선하고, 근거 표결이 바뀌면 기존 해석을 숨깁니다.
- 뉴스: 사용자가 저장·가공 권한을 확인한 제목 JSON만 현재 방문 메모리에서 처리합니다. 외부 AI에 보내지 않습니다. 국회 API 키는 뉴스 이용 권한을 대신하지 않습니다.
- 추적: 브라우저의 `pandan.politicians.v1`에 저장됩니다. 계정 간 동기화·상시 알림은 없습니다.
- 실제 화면에는 가상 인물이 없습니다. 개발 테스트용 시연은 `VITE_ENABLE_DEMO=true`를 명시한 빌드에서만 활성화됩니다.
- 한 의안의 행동을 장기 성향이나 숨은 의도의 확정 근거로 일반화하지 않습니다. 시나리오는 예측 확률이 아닙니다.

## 검사

```sh
npm test
npm run typecheck
npm run build
npm run audit:public
```

테스트는 외부 API와 키 없이 실행됩니다. 공개 검사는 Git에 추적된 파일과 새로 스테이징한 파일을 확인하며 비밀값·내부 파일명 차단 규칙을 적용합니다.
검사 통과는 모든 보안 위험이 없다는 보증이 아닙니다. 별도 린트 도구는 설정하지 않았습니다.
